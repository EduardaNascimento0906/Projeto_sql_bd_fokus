# Banco de Dados Fokus | SQL

## Sobre o projeto

Este projeto foi desenvolvido **para fins acadêmicos**, com o objetivo de praticar a linguagem SQL por meio de consultas realizadas em uma base de dados fictícia da empresa Fokus.

Utilizando o MySQL Workbench, foram explorados diferentes recursos SQL para consultar informações, realizar cálculos, verificar dados cadastrais e aplicar condições lógicas.

O repositório reúne os arquivos SQL utilizados durante as atividades práticas, organizados para facilitar a leitura, a compreensão dos comandos e a consulta dos códigos.

> **Importante:** a base de dados utilizada é fictícia e destinada exclusivamente a fins acadêmicos, não representando informações reais de uma empresa ou de pessoas.

## Tecnologias e ferramentas

* **SQL:** linguagem utilizada para consultar e analisar os dados.
* **MySQL:** sistema gerenciador de banco de dados.
* **MySQL Workbench:** ferramenta utilizada para executar consultas e visualizar resultados.
* **GitHub:** plataforma utilizada para armazenar e compartilhar o projeto.

## Estrutura do banco de dados

A base de dados fictícia contém tabelas relacionadas às operações e aos colaboradores da Fokus.

| Tabela             | Descrição                                                                                      |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| `colaboradores`    | Informações cadastrais dos colaboradores fictícios.                                            |
| `dependentes`      | Informações relacionadas aos dependentes.                                                      |
| `faturamento`      | Dados financeiros, como faturamento bruto, despesas, lucro líquido e número de novos clientes. |
| `historicoemprego` | Informações relacionadas ao histórico profissional e aos salários.                             |
| `licencas`         | Informações relacionadas a licenças.                                                           |
| `treinamento`      | Informações relacionadas a treinamentos.                                                       |

## Comandos e recursos SQL utilizados

Durante o desenvolvimento do projeto, foram utilizados os seguintes comandos e recursos:

| Comando ou recurso                | Finalidade                                                       |
| --------------------------------- | ---------------------------------------------------------------- |
| `SELECT`                          | Consultar e selecionar dados das tabelas.                        |
| `WHERE`                           | Filtrar registros de acordo com condições especificadas.         |
| `LIKE`                            | Pesquisar valores com base em padrões de texto.                  |
| `SUM()`                           | Calcular a soma de valores.                                      |
| `AVG()`                           | Calcular a média de valores numéricos.                           |
| `MAX()`                           | Identificar o maior valor de um conjunto de dados.               |
| `MIN()`                           | Identificar o menor valor de um conjunto de dados.               |
| `GROUP BY`                        | Agrupar registros com base em uma ou mais colunas.               |
| `LENGTH()`                        | Verificar a quantidade de caracteres de um valor textual.        |
| `CASE WHEN`                       | Aplicar condições e classificar dados conforme regras definidas. |
| Concatenação                      | Combinar informações de diferentes colunas em um único texto.    |
| Aliases (`AS`)                    | Definir nomes alternativos para colunas e resultados.            |
| `BETWEEN`                         | Filtrar valores dentro de um intervalo.                          |
| Operadores lógicos e comparativos | Construir condições para filtrar e classificar dados.            |

## Objetivo acadêmico

O projeto tem como finalidade consolidar conhecimentos em SQL e desenvolver habilidades práticas na consulta e análise de dados relacionais.

A realização dessas atividades contribui para o aprimoramento do raciocínio lógico, da compreensão de consultas SQL e da utilização de funções para extrair informações de um banco de dados.
